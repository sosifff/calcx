ЧТО ЭТО ТАКОЕ
Плагин — это маленькая программа в виде текста. Она добавляет
в калькулятор КНОПКИ над клавиатурой и СВОИ ФУНКЦИИ для формул.
Текст между « слэш-звёздочка » и « звёздочка-слэш » (как этот)
и строки после двух слэшей — это комментарии. Калькулятор их
не читает, они нужны только людям.

КАК УСТАНОВИТЬ
1. Открой вкладку «Плагины».
2. Нажми «＋ Вставить код».
3. Удали весь текст в окошке и вставь сюда этот файл.
4. Нажми «Установить». Плагин сразу включится.
Выключить или удалить плагин можно там же, во вкладке «Плагины».

КАК ПЕРЕДЕЛАТЬ ПОД СЕБЯ
Меняй только то, что стоит внутри кавычек ' ' и числа.
Скобки { } ( ) , ; кавычки и слова вроде onClick не трогай.
Каждая строка с кнопкой или функцией заканчивается на ; или ,
как в примере. Если что-то не работает, смотри раздел
«ЧАСТЫЕ ОШИБКИ» в самом низу.

──────────────────────────────────────────────────────────────
ВСЕ КОМАНДЫ (объект api) — других команд нет
──────────────────────────────────────────────────────────────
api.addButton({ label:'текст на кнопке', insert:'что вставить' })
    Кнопка, которая вставляет текст в формулу.

api.addButton({ label:'текст', onClick: a => { ... } })
    Кнопка с действием. Внутри фигурных скобок пишешь, что делать.
    Буква «a» — это тот же api, пользуйся им как api.
    (Запись «a => { ... }» читается как «действие для a».)

api.addFunction('имя', x => формула_с_x)
    Своя функция. Пример: api.addFunction('cube', x => x ** 3)
    После этого в калькуляторе работает cube(3), результат 27.
    Здесь x — число, которое пользователь напишет в скобках.

api.insert('текст')       добавить текст в конец формулы
api.getExpr()             узнать текущую формулу (как текст)
api.getResult()           узнать результат формулы (как число);
                          если формула неверная, вернёт NaN
api.setExpr('текст')      заменить формулу целиком
api.vibrate(20)           вибрация 20 миллисекунд
api.vibrate([10,30,10])   узор: вибро 10, пауза 30, вибро 10
api.toast('текст')        всплывающее сообщение внизу экрана

// ══════════════════ ПРИМЕР ПЛАГИНА (рабочий) ══════════════════

registerPlugin({

  // Уникальное имя плагина: латиница, без пробелов
  id: 'my-plugin',

  // Название, описание, версия и автор — видны в списке плагинов
  name: 'Мой плагин',
  description: 'Пример: константа, свои функции, скидка и округление',
  version: '1.0',
  author: 'Твоё имя',

  // Сюда пишем всё, что должно появиться в калькуляторе
  onLoad(api) {

    // ── 1. ПРОСТАЯ КНОПКА-КОНСТАНТА ─────────────────────────
    // На кнопке написано «g», при нажатии вставляется 9.81
    api.addButton({ label: 'g', insert: '9.81' });

    // ── 2. СВОИ ФУНКЦИИ ─────────────────────────────────────
    // cube(3) = 27     half(10) = 5
    api.addFunction('cube', x => x ** 3);
    api.addFunction('half', x => x / 2);

    // Кнопки, которые вставляют эти функции в формулу.
    // Скобку «(» мы вставляем сами, остаётся ввести число и «)»
    api.addButton({ label: 'cube', insert: 'cube(' });
    api.addButton({ label: 'half', insert: 'half(' });

    // ── 3. КНОПКА С ДЕЙСТВИЕМ: УДВОИТЬ РЕЗУЛЬТАТ ────────────
    api.addButton({
      label: '×2',
      onClick: a => {
        const v = a.getResult();               // берём результат
        if (isNaN(v)) {                        // если формула неверная
          a.toast('Сначала введите выражение');
          return;                              // и выходим
        }
        a.setExpr(String(v * 2));              // записываем ответ × 2
        a.vibrate(20);                         // лёгкая вибрация
      }
    });

    // ── 4. КНОПКА: СКИДКА 15% ───────────────────────────────
    api.addButton({
      label: '−15%',
      onClick: a => {
        const v = a.getResult();
        if (isNaN(v)) return a.toast('Введите число');
        const itog = Math.round(v * 0.85 * 100) / 100;  // 2 знака после точки
        a.setExpr(String(itog));
        a.toast('Скидка 15% применена');
        a.vibrate([10, 30, 10]);
      }
    });

    // ── 5. КНОПКА: ОКРУГЛИТЬ ДО ЦЕЛОГО ──────────────────────
    api.addButton({
      label: 'округл.',
      onClick: a => {
        const v = a.getResult();
        if (isNaN(v)) return a.toast('Введите число');
        a.setExpr(String(Math.round(v)));
      }
    });

    // ── 6. ДВА ЧИСЛА БЕЗ ЗАПЯТОЙ: НОД ЧЕРЕЗ КНОПКУ ──────────
    // Функцию от двух чисел сделать нельзя, но можно так:
    // набери «12÷18», нажми «НОД», получишь 6
    api.addButton({
      label: 'НОД',
      onClick: a => {
        const e = a.getExpr();
        const m = e.match(/^(\d+)÷(\d+)$/);    // ищем «число÷число»
        if (!m) return a.toast('Введите так: 12÷18');
        let x = +m[1], y = +m[2];
        while (y) { [x, y] = [y, x % y]; }     // алгоритм Евклида
        a.setExpr(String(x));
        a.toast('Наибольший общий делитель: ' + x);
      }
    });
  },

  // Вызывается при выключении плагина. Кнопки и функции
  // убираются сами, поэтому здесь можно ничего не писать.
  onUnload() {}
});
